# Changelog

Notable changes to `opencode-themes` are recorded here.

## [1.0.1] - 2026-11-09

### Added

- GitHub Packages distribution as `@isavonxz-type/opencode-themes`.
- Automated public package publishing when a GitHub Release is published.

## [1.0.0] - 2026-11-09

### Added

- Nine OpenCode Desktop themes with light and dark variants.
- Palette-driven preview gallery for all themes.
- Automated theme validation and GitHub Actions build checks.

### Changed

- Improved contrast for syntax comments and Markdown horizontal rules across themes.
